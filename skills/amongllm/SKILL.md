## Development Workflow

1. Understand the request
2. Determine whether the project is an all-client mod or a host-only mod
3. Inspect existing patches for the modding protocol already in use
4. Ask the user when the mode or protocol cannot be determined
5. Record the confirmed mode and protocol in project memory
6. Implement and verify the change
